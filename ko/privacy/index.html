운영 정보 개인정보 처리방침 이용약관

NEXTA 설립 준비팀(이하 ‘운영자’)은 이 사이트를 통한 문의 과정에서 받은 정보를 아래 기준에 따라 처리합니다.

1. 수집하는 정보

이메일로 문의하면 발신 이메일 주소, 이름, 현재 활동 내용, 선택적으로 제공한 SNS 계정, 문의 내용을 수집합니다.

‘이메일로 상담하기’를 누르면 사용 중인 이메일 앱이 열립니다. 사이트에서 선택한 활동 정보나 문의 내용은 이 페이지에서 자동으로 전송되지 않습니다.

첫 문의에는 본인 확인 서류, 은행 계좌 정보, 비밀번호 등을 제공할 필요가 없습니다.

2. 이용 목적

수집한 정보는 문의에 답변하고, 원하는 활동과 지원 내용을 확인하며, 해당 상담과 관련해 연락하는 데 이용합니다. 다른 목적으로 이용할 때에는 법령에 따라 필요한 사항을 설명하고 동의 등의 절차를 거칩니다.

3. 정보 보호 및 제3자 제공

문의에 응대하는 데 필요한 범위에서만 정보를 처리하며, 무단 접근이나 유출 등을 방지하기 위해 필요한 관리 조치를 취합니다.

법령에 근거가 있는 경우를 제외하고, 본인의 동의 없이 개인정보를 제3자에게 제공하지 않습니다. 이메일 보관 등을 위해 외부 서비스에 정보 처리를 위탁하는 경우에는 이용 목적의 범위에서 필요한 관리·감독을 합니다.

4. 보관 및 삭제

정보는 상담에 필요한 기간 또는 법령상 보관이 필요한 기간 동안만 보관합니다. 더 이상 이용할 필요가 없는 정보는 적절한 방법으로 삭제합니다.

5. 사이트 접속 정보

이 사이트는 자체 접속 분석 도구나 광고 태그를 사용하지 않습니다. 운영자는 방문자를 추적하기 위한 쿠키를 설정하지 않습니다.

이 사이트는 GitHub Pages를 통해 제공됩니다. GitHub는 보안을 위해 방문자의 IP 주소를 기록하고 보관합니다. 자세한 정보 처리 기준은 GitHub 개인정보 처리방침에서 확인할 수 있습니다.

GitHub 개인정보 처리방침

6. 개인정보 열람·정정·삭제·이용 중지 요청

본인의 정보에 대한 열람, 정정, 삭제, 이용 중지 등을 요청하려면 아래 연락처를 이용하시기 바랍니다. 운영자는 본인 여부와 요청 내용을 확인한 후 적용 법령에 따라 처리합니다.

7. 처리방침 변경

정보 처리 방식이 달라지면 이 방침을 검토하고 변경 내용을 이 페이지에 게시합니다. 변경 사항에 대해 법령상 동의 등의 절차가 필요한 경우에는 해당 절차를 거칩니다.
